# Job-Internship-Tracker

A full-stack web application designed to help students organize and manage their job and internship search in one place.

The platform allows users to track applications, monitor application status, manage important deadlines, and keep their job-search activities organized.

---

##  Project Overview

Finding in which internships and jobs often involves applying to multiple companies at the same time.

Students may need to keep track of:

- Which companies they applied to
- Which role they applied for
- Application status
- Interview dates
- Application deadlines
- Important links
- Upcoming opportunities
- Rejected and shortlisted applications

Managing all of this through spreadsheets, notes, bookmarks, and emails can become difficult.

The **Job-Internship-Tracker** was created to provide a centralized platform for managing the complete application journey.
